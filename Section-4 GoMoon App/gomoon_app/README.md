# 🚀 GoMoon – Flutter Space Travel UI

A simple Flutter UI project built to practice Flutter fundamentals by creating a modern and responsive mobile application.

This project focuses on applying core Flutter concepts such as responsive layouts, reusable widgets, custom components, and clean project structure.

---

## ✨ Features

- 🌙 Modern dark-themed interface
- 🚀 Space travel booking UI
- 📍 Select destination station
- 👨‍🚀 Choose the number of travelers
- 🎫 Select travel class (Economy, Business, First, Private & VIP)
- 📱 Responsive UI using MediaQuery
- ♻️ Reusable custom dropdown widget
- 🖼️ Asset image integration
- 🎨 Material Design components
- 🏗️ Clean and organized project structure

## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/usman-383/Complete-Flutter-Dart-Course-Udemy-/edit/main/Section-4%20GoMoon%20App/gomoon_app
```

### Navigate to the project

```bash
cd gomoon_app
```

### Install dependencies

```bash
flutter pub get
```

### Run the application

```bash
flutter run
```
